# L2 Assay

The assay is intentionally isolated and deterministic.

Scientific execution is `representation_revision.assay.run_scientific_assay()`.

The first checkpoint is pre-certification of the finite revision universe, discrimination, and adoption. Only after those pass should the recorded adaptive-vs-shadow execution be produced.

The assay does not implement L3. The fixed-G shadow receives the identical held-out `(S_future, e_future)` event stream as the adaptive branch; persistent generator identity is the treatment difference.
